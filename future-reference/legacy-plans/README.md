# Legacy Plans

This directory contains previous versions of the Cayana product plan and roadmap.

## Archived Documents

- **`Cayana_Product_Plan_v0.2.md`**
- **`Cayana_Agent_Development_Roadmap_v0.2.md`**

## Context

These v0.2 documents represented an early design phase where Cayana Cloud, multi-device synchronization, and third-party agent ecosystems were planned alongside core local memory capture.

For **Cayana v1 MVP**, the product strategy was refined to emphasize uncompromising local privacy, zero backend dependency, and rock-solid local memory retrieval with Google Drive backup.

The active, authoritative specifications for v1 MVP are located in the repository root:
- [`Cayana_Product_Plan_v1_MVP.md`](../../Cayana_Product_Plan_v1_MVP.md)
- [`Cayana_Agent_Development_Roadmap_v1_MVP.md`](../../Cayana_Agent_Development_Roadmap_v1_MVP.md)
